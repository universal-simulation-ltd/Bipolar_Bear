# Localised App Store / Play Store listing copy

Paste-ready translations of `listing.md` for the three largest markets among
the app's supported locales: **Spanish (es), French (fr), German (de)**.

Draft copy — have a native speaker skim the voice before submitting. Character
counts are noted for the fields Apple limits tightly (they count Unicode
characters, so accented letters = 1). App **names stay as the brand**
("Bipolar Bear" / "Bipolar Anonymous") — don't translate them.

Store-listing language ≠ in-app language: these go into App Store Connect
(add a Localization per language) and Play Console (Main store listing →
Manage translations). See the note at the bottom about the iOS "Languages"
field for a Capacitor app.
